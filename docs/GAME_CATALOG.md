# Game Catalog - 100 Classic Arcade Games

Archetype codes are defined in [ARCHITECTURE.md](ARCHITECTURE.md). Size = implementation effort once the archetype exists: **S** about 1 day, **M** 2-4 days, **L** 1-2 weeks.

Titles are the historic names used to describe the game style. Shipped games use **original names, art and audio** unless licensing is cleared (see [LEGAL.md](LEGAL.md)); the `slug` is internal and the public `title` may be a renamed homage.

Status: `todo` -> `spec` -> `dev` -> `qa` -> `live`.
